# Velocity FPS

Jeu de déplacement à la première personne pour navigateur de bureau : balade libre à très haute vitesse
(bunny hop, surf, glissade) dans une friche industrielle originale, « Friche Ardente ».

- **Jouer** : ouvrir [`index.html`](index.html) dans un navigateur de bureau (fichier autonome, rien à installer).
- **Sources, build et tests** : voir [`web/README.md`](web/README.md).

Commandes : ZQSD/WASD, souris, Maj (sprint), Espace maintenu (bunny hop), Ctrl (frein), C (glissade/plongeon),
F (inspecter le couteau), Échap (pause et réglages). Limite technique : 400 m/s.
